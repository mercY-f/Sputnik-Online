# План модернизации интерфейса «Спутник-Онлайн»

Принципы: меньше панелей, у каждой одна задача; сначала итоговый макет, потом перенос; один шаг — один локальный коммит (без push); после этапа — тесты, сборка и скриншот пользователя.

## Решения пользователя
- Модели: процедурные из примитивов Three.js; glTF только для МКС и телескопа.
- Луна / другая планета: добавить позже как демонстрацию расширяемости проекта (аргумент для комиссии). Пока этап D.
- Блок «Когда увидеть» над городом: в макете и в реальном проекте.
- Нижняя панель времени: не нужна.
- Интерфейс только на русском.

## A. Макет (docs/mockups/ui-redesign.html)
- A1 Раскладка: глобус на весь экран; шапка (лого, поиск ⌘K, UTC, профиль). Убрать рейку, каталог, легенду, футер.
- A2 Поиск с выпадающим списком, чипсы категорий, «О данных» в меню.
- A3 Правая карточка: Орбита / След / Следить / Поделиться, параметры с подсказками, эпоха TLE, связанные спутники.
- A4 Блок «Когда увидеть» по городу.
- A5 Силуэты моделей по категориям (SVG-заглушки).
- A6 Мобильная версия (bottom-sheet, 390px).
- A7 Типографика и цвет: один акцент, плотная сетка, меньше свечения.
- A8 Заготовка переключателя «Земля / Луна» (визуально, без логики).

## B. Подготовка моделей
- Замер FPS текущего InstancedMesh на машине пользователя.
- Схема LOD: далеко — Points по цвету категории; средне — InstancedMesh на категорию (30–80 треугольников); близко — детальная модель выбранного спутника.
- Категории: МКС (glTF), Starlink, OneWeb, Iridium, навигация, погода, телескоп (glTF), прочее.

## C. Перенос в проект (по коммиту на шаг)
C1 токены и GlassPanel · C2 шапка и поиск ⌘K · C3 чипсы категорий · C4 правая карточка (на базе SatelliteCard.vue) · C5 удаление старого сайдбара и дублей · C6 новости в меню шапки · C7 пролёты над городом (SGP4 уже есть) · C8 модели по категориям · C9 мобильные bottom-sheet · C10 тесты, npm run build, скриншоты.

## D. Расширение
Луна (текстура + положение по эфемеридам), переключатель «Земля / Луна».

## Риски
Производительность моделей (замер до C8); пролёты требуют ввода города и аккуратного SGP4; Луна требует эфемерид.
