# План: редизайн «1-бит / бумага / ретро-телеметрия»

Статус: черновик на утверждение. Сначала макет (`docs/mockups/`), затем перенос в Laravel/Vue. Один шаг = один локальный коммит, без push.

## 0. Оценка идеи

**Одобряю.** Причины:
- Различимость. Стекло + неон + тёмная тема есть у всех трекеров (N2YO, Stuff in Space, Starlink-карты). Бумага + моноширинный шрифт + картографические границы на таком фоне не встречаются.
- Хорошо ложится на диплом: есть связный визуальный язык и обоснование (картография, документация NASA/ESA, терминалы).
- Дешевле по ресурсам: не нужны текстуры Земли (≈1.3 МБ WebP), bloom, ACES, FXAA, атмосфера. Это даёт выигрыш по FPS и размеру бандла.
- Буквы вместо цвета дают читаемость для дальтоников. Категория видна без легенды.
- Спецификация детальная, токены однозначные.

**Что может не сработать (риски, по убыванию):**
1. **Плотность глифов.** Starlink — тысячи объектов. Буквы `S` слипнутся в кашу. LOD в ТЗ предусмотрен, но пороги надо подбирать глазами. Это главный риск.
2. **Тёмная сторона Земли.** На бумажном глобусе терминатор нужен, иначе теряется «живость». Предлагаю ординарный Bayer-дизеринг (шейдер, 1-бит) вместо плавной тени. Это не в ТЗ, но укрепляет стиль.
3. **Отрисовка границ.** Нужен GeoJSON/TopoJSON (Natural Earth 110m, домен общественного достояния, ~100–150 КБ). Пакета `world-atlas` в `node_modules` нет, его надо добавить (или положить файл в `public/data/`).
4. **Противоречия с вашими прежними решениями** — нужен ваш выбор (см. §1).
5. **Скорость симуляции (`PAUSE/1x/10x/100x`).** В проекте её нет: SGP4 считается на «сейчас». Нужен виртуальный часы-контекст, влияет на воркер, интерполяцию, орбиты и «Когда увидеть». Это отдельная задача, не декор.
6. **Размер `Pages/Globe/Index.vue` (3301 строка).** Переносить придётся с одновременной декомпозицией, иначе правки будут дорогими.
7. **Читаемость мелкого моно-текста 10 px** на бумажном фоне допустима, но минимальный размер надо поднять до 11 px (также на мобильном).

## 2. Токены и правила (единый источник)

CSS-переменные в `:root` (макет) → потом `tailwind.config.js` + `resources/css/app.css`:

```
--paper:#F4F1EA  --ink:#0E0E0E  --ink-muted:#5C5A54  --surface:#E8E4DA
--bw-1:1px  --bw-2:2px  --radius:0  --shadow-hard:2px 2px 0 var(--ink)
--font-mono:"JetBrains Mono","IBM Plex Mono",ui-monospace,monospace
```
Правила:
- `border-radius:0`, без `blur`, `gradient`, мягких теней. Единственная «тень» — жёсткий сдвиг. `:active` — `translate(1px,1px)` + тень 1px.
- Сетка-точки: `radial-gradient(#0E0E0E 0.5px,transparent 0.5px)`, 20px, opacity .08, на `body::before`, `pointer-events:none`.
- `font-variant-numeric: tabular-nums` на классе `.num` (UTC, высота, скорость, наклонение, координаты, счётчики).
- Метки: 11px uppercase, `letter-spacing:.12em`, `--ink-muted`. Значения: 13px `--ink`. Заголовки: 700, uppercase, `tracking-wider`.
- Фокус клавиатуры: `outline:2px solid var(--ink); outline-offset:2px` (обязательно, это доступность).
- `prefers-reduced-motion`: отключить мигание курсора и анимации перелёта.
- Шрифт: подключить локально (woff2 в `public/fonts/`, не CDN — офлайн-PWA и приватность). JetBrains Mono, subset кириллицы + латиницы.
- Контраст `#0E0E0E` на `#F4F1EA` ≈ 17:1; `#5C5A54` на бумаге ≈ 6:1 — проходит AA. Проверить после сборки.

### 3.1 Глобус в макете (A7) — подшаги
1. **Vendor.** `docs/mockups/vendor/globe.gl.min.js` (из `node_modules/globe.gl/dist`) + `ne_110m_countries.geojson` (или TopoJSON + `topojson-client` min). Всё локально.
2. **Земля.** `globeImageUrl(null)`, материал сферы — `MeshBasicMaterial` цвета бумаги. Границы — `polygonsData` с `polygonCapColor: transparent`, `polygonStrokeColor:#0E0E0E`, `polygonAltitude:0.001` (если не даёт 1px линию — `pathsData` по контурам, либо `LineSegments` вручную).
3. **Силуэт.** Inverted hull: вторая сфера радиуса `R*1.008`, `side:BackSide`, чёрная. Это даст 2–3 px контур независимо от зума. Fresnel не нужен.
4. **Фон.** `backgroundColor('rgba(0,0,0,0)')`; атмосферу `showAtmosphere(false)`; слой «ATMOSPHERE» в 1-бите = тонкое пунктирное кольцо второго радиуса (dashed), не свечение.
5. **Сетка.** `graticules` (`showGraticules(true)` у globe.gl) → заменить на собственные линии через `LineDashedMaterial`, opacity .25, шаг 30°.
6. **Терминатор (решено 2026-11-15, взамен откатанной Стадии 3).**
   - **Семантика солнца:** солнце закреплено в системе координат глобуса и вычисляется по текущему UTC (субсолнечная точка: склонение + часовой угол, низкоточная формула NOAA). Обновляется с тиком UTC-часов. Перетаскивание камеры солнце **не** двигает: при развороте к ночной стороне видны точки, ползёт терминатор только со временем.
   - **Интеграция с three.js:** через `window.THREE` — в `vendor/` кладём `three.module.min.js` + `three.core.min.js` (three 0.183.2 из `node_modules`, та же версия, под которую собран globe.gl 2.45), подключаем **до** `globe.gl.min.js`: бандл globe.gl при наличии `window.THREE` использует его целиком (проверено по коду бандла), и `Globe.THREE` экспортирует полный набор классов, включая `ShaderMaterial`/`Vector3`. Хаки через `pathsData`/`traverse` **запрещены**.
   - **Реализация:** замена материала сферы Земли (не купол поверх — без z-fighting): `dot(normal, sunDir)` → ordered dithering Bayer 4×4 по `gl_FragCoord`; днём бумага `#F4F1EA`, ночью чёрные точки `#0E0E0E`, плотность ограничена константой (≈0.75 — точки с просветами бумаги, не сплошная заливка), у терминатора плавный переход плотности. Порог плотности — константа `NIGHT_MAX_DENSITY`.
   - Включается чекбоксом `TERMINATOR` (низ справа), по умолчанию вкл. Не зависит от `extinguishLights` (`ShaderMaterial` не завязан на свет).
   - Перед встраиванием — изолированный мини-тест (сфера + один шейдер, `mix(день, ночь, step)`): `docs/mockups/terminator-test.html`, остаётся как рабочий прототип.
7. **Спутники.** Глиф-атлас: Canvas 2D → текстура 8 клеток (S O N T I R W ×) в моно-шрифте; `InstancedMesh` с плоскостями-билбордами и атласными UV, **или** `THREE.Points` + `ShaderMaterial`, который берёт UV из атрибута категории. Рекомендую второй: один draw call, бесплатный LOD (размер точки зависит от расстояния камеры), нет матриц на CPU.
8. **LOD.** По `distance` камеры: `> 2.2R` → квадратные точки 2 px чёрные; `1.4–2.2R` → глифы, но не более N ближайших к экранному центру и выбранной категории; `< 1.4R` → все глифы выбранной группы. Пороги вынести в константы `LOD`.
9. **Выбор.** Рейкаст по Points (порог 10px), курсор `crosshair`. Выбранный: `[ ● ]` как отдельный спрайт, пунктирный трек (`LineDashedMaterial`, `computeLineDistances()`), HTML-плашка `ONEWEB-0210 [O]` с лидер-линией, позиция — `camera.project()`, обновление в rAF, скрывать при заходе за лимб.
10. **Перелёт.** `pointOfView({lat,lng,altitude},700)`.

Что **не** делаем в макете: SGP4, API, сборку. Положение берём из `SATELLITES` (`lat,lng,alt`), движение — простая линейная прокрутка долготы по времени.

## 7. Проверка качества (на каждом шаге)
- Автоматически: `grep -nE "border-radius:\s*[1-9]|rounded-|blur|gradient|backdrop|text-shadow"` по новым файлам (исключения — точечно разрешённая сетка) → пусто.
- Токены: в новых файлах нет `#hex` кроме четырёх токенов.
- Русификация: grep английских слов в UI (кроме UTC, NORAD ID, STARLINK, ONEWEB, TLE, единиц измерения).
- Производительность: FPS, число draw calls (`renderer.info`) до/после — в записку диплома.
- Визуал: скриншоты делаете вы в Windows-браузере (в WSL WebGL не запускается).
