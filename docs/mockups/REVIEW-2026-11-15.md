## Пакет S1 — UI / логика (субагент 1)
1. **П8, остаток:** `generatePasses` — перенос суток: метка дня вычисляется по кумулятивному смещению часов (СЕГОДНЯ/ЗАВТРА/ПОСЛЕЗАВТРА), а не берётся из статического массива.
2. **П8:** заголовок `АЗИМУТ` → `НАПРАВЛЕНИЕ` (это направление, а не градус азимута); убедиться, что `МАКС` и `НАПРАВЛЕНИЕ` не сливаются при gap 4px.
3. **П9:** `boot()` читает `location.hash` (`#sat=<id>`), выбирает спутник; слушать `hashchange`.
4. **П10:** в labelTag убрать дубль буквы: `${s.name}` (буква уже в глифе).
5. **П6:** `.chip-ribbon-bar` — сдвиг при открытых панелях: `body.inspector-open` → `right: 332px` (и `left: 296px` при открытом каталоге, если он слева; уточнить по факту), чтобы лента не резалась.
6. **П7, мобилка 390px:** взаимоисключающие bottom-sheet (клик по строке каталога закрывает каталог; открытие каталога закрывает инспектор и наоборот); `.btn-square`/`#btn-catalog-toggle`/поиск — цели ≥ 40px.
7. **П12:** слои-чекбоксы перевести на русский: `СЕТКА / ОРБИТЫ / АТМОСФЕРА / ТЕРМИНАТОР / ПОДПИСИ` (символы `[■]` остаются).

## Пакет S2 — сцена / геометрия (субагент 2)
1. **П1:** `updateSelectedOrbit` — фаза орбиты от текущей позиции спутника (`lat0=sat.lat`, не экватор): орбита проходит через маркер; для 3D-кольца (`orbitMesh`) **не** вычитать `earthRotation`, только для наземного следа `trackMesh`.
2. **П2:** кольцо ATMOSPHERE: радиус и центр от перспективной проекции лимба (`R / sqrt(camDist² − R²)`, центр = проекция центра Земли), радиус ≥ радиуса силуэта (101.2), чтобы не резать континенты.
3. **П3:** лимб-куллинг — пересечение луча камера→спутник со сферой R=100 (а не проверка для точек на поверхности), чтобы спутники на высоте не пропадали у края диска на фоне пустой бумаги.
4. **П4:** независимость СЛЕД/ОРБИТА: `trackMesh.visible = !!state.layers.track` (без `&& state.layers.orbits`), скрытие орбиты не трогает след и наоборот.
5. **П5, минимум:** выкинуть мёртвый `createGlyphAtlas` (или задействовать — но это B2); привести пороги LOD к плану: FAR > 2.2R, MID 1.4–2.2R. Полная миграция на `THREE.Points` — **не в этом пакете**.

## Осознанно откладываем
- **П5, полная миграция глифов на THREE.Points + ShaderMaterial** (один draw call, LOD из шейдера) → **Этап B2**, где это проверяется на 10–15 тыс. объектов. В макете 15 сатов — выигрыша нет, а риск сломать рабочий рендер высок.
- **П11, локальный @font-face JetBrains Mono** (нужен woff2 + лицензия) → **Этап C1** (шрифты в `public/fonts/`). Порог кегля 11px — правим сейчас (S3).
- **П11, кегль 9px→11px, 10px→11px** → отдельным малым шагом S3, чтобы не смешивать с логикой.
